ИИ‑агент для бухгалтерии и системного администрирования

Чьи задачи это закрывает

Бухгалтер: требования ФНС в срок; завал первички; сверки; выписки.
Сисадмин: ночные сбои; бэкапы; рутинные настройки.
Руководитель: снять эти часы и риски с сотрудников.

Что предлагается

ИИ-агент — программа на компьютере сотрудника.
Ей ставят задачу обычным текстом.
Она читает документы, сверяется с 1С, готовит ответы, проводки, настройки.
Правило одно: агент готовит — человек проверяет и утверждает.

Что уходит наружу

Между агентом и ИИ стоит фильтр обезличивания.
Наружу уходят подменённые имена, ИНН и счета — по виду настоящие.
Словарь замен остаётся только у вас. Ответ восстанавливается обратно.
Подмена не разрешилась — выдача останавливается.

1. Что это и как работает

ИИ-модель сама по себе только отвечает текстом. Агент — это модель плюс программа-исполнитель. Цикл простой: модель предлагает шаг — программа выполняет (открыть файл, запросить 1С, запустить команду) — результат возвращается модели — следующий шаг.

Так это описывает Anthropic: «Claude Code is an agentic coding tool that reads your codebase, edits files, runs commands» — читает ваши файлы, редактирует их, запускает команды. «Кодовая база» здесь — любые рабочие файлы, включая 1С.

Важно: агент работает на вашем компьютере — «runs locally in your terminal and talks directly to model APIs». В интернет уходят только тексты запросов. Поэтому один фильтр на этом пути покрывает исходящий канал к модели.

Подключение к 1С не требует переписывания конфигурации. Платформа сама даёт веб-доступ: «REST интерфейс позволяет читать данные 1С:Предприятия, изменять их, создавать новые» (v8.1c.ru). Нужны три штатных шага администратора: опубликовать базу на веб-сервере, выбрать состав объектов OData, завести служебного пользователя. Проверено для ПРОФ, КОРП и 1С:Фреш; на базовых версиях не подтверждено. Отчётность — через API оператора: «Отправить сформированную отчетность в контролирующий орган. Отследить и завершить документооборот» (Экстерн; так же у СБИС).

2. Как выглядит рабочий день

Бухгалтер: «Разбери требование ФНС, сверь с базой, подготовь опись и проект ответа, расхождения — таблицей». Агент получает требование по API (есть автопроверка Check-Demand), сверяется с 1С, собирает пакет. Человек проверяет и утверждает: по нашей оценке 10–15 минут там, где ручной цикл занимает часы. Цифру замеряем на вашем потоке в первый месяц — она войдёт в приёмку.

Первичка: скан → распознавание («автоматизировать ввод первичных бухгалтерских документов в базу», ocr.1c.ai — от 3 ₽ за страницу, подписчикам ИТС первые 250 страниц бесплатно) → проводки пакетом на подтверждение. Сверка: электронный формат акта сверки действует с 21.07.2022; он добровольный, но именно он сверяется автоматически. Выписки: штатный 1С:ДиректБанк — платёжные поручения поддерживают более 40 банков, автоматические выписки пока шесть.

Сисадмин: «Сайт не открывается — найди причину». Агент читает логи, называет причину и команду починки. Применяет человек. «Настрой ежедневную копию базы 1С с проверкой восстановления» — агент пишет скрипт и расписание, включает после подтверждения.

Часть возможностей доступна без дополнительных покупок — поверхности у вас есть: OData включается в вашей 1С штатно; API Экстерна и СБИС — по заявке оператору, цена не публикуется и обсуждается отдельно. Для ваших разработчиков 1С:Напарник в среде 1С:EDT бесплатен подписчикам ИТС до 01.10.2026 — это инструмент программиста, не бухгалтера.

3. Как данные остаются под защитой

«ООО „Ромашка«, ИНН 7712345671» → наружу «ООО „Пион», ИНН 7787654324». Формат и контрольные цифры сохранены — модель работает как с настоящими. Словарь «Ромашка ↔ Пион» — только у вас. Ответ вернулся — снова «Ромашка».

Это штатный механизм открытых инструментов. Presidio: «the user/client is holding the entity_mapping … use it for de-anonymization» — словарь замен держит клиент, значит восстановить имена может только он. Готовые шлюзы делают обратную замену прямо в ответе (LiteLLM: «replace the masked token with the user-submitted values»).

Известный сбой класса задокументирован там же: «LLM responses can sometimes contain the masked tokens» — модель может вернуть подмену в искажённом виде. Поэтому правило: неразрешённая подмена останавливает выдачу — искажение видно человеку до отправки.

Русские реквизиты: ИНН, КПП и счета распознаются правилами с контрольными цифрами; имена и адреса — нейрораспознавателем на обычном процессоре.

Право. 152-ФЗ, ст. 18 ч. 5: запись и хранение персональных данных россиян «с использованием баз данных, находящихся за пределами территории Российской Федерации, не допускаются». Исключения перечислены там же и обычной хозяйственной деятельности не покрывают. Бухгалтерия держит чужие персональные данные и чужую коммерческую тайну (98-ФЗ) и отвечает за них по договору. Отсюда правило на каждый день — даже без этого решения: во внешний ИИ данные идут только обезличенными, словарь замен храните у себя. Для зарубежного варианта дополнительно: «does not train generative models using code or prompts … under commercial terms» — но это условие корпоративных тарифов (Team, Enterprise, API), а не личных: на личной подписке гарантия не действует. Режим нулевого хранения (Zero Data Retention) в стандартный Enterprise не входит — его включает Anthropic по отдельной заявке.

4. Почему агенту не дают полную свободу

Три случая, последний — этой весной. Апрель 2026: агент Cursor с моделью Claude Opus 4.6 удалил рабочую базу компании PocketOS и все резервные копии — одним вызовом к хостингу, за девять секунд; копии лежали в том же томе. Июль 2025: агент сервиса Replit стёр базу, которую сам сервис пометил как рабочую, — «This was a catastrophic failure on my part» (признание самого агента; данные потом восстановили из отката). Тогда же в помощник Amazon Q посторонней правкой внедрили команду-стиратель — бюллетень AWS-2025-015; сработать она не успела.

Выводы встроены в решение — и годятся как правила для любого ИИ в компании: рабочая и тестовая среды разделены; любое изменение — сначала вхолостую, потом подтверждение; песочница на уровне операционной системы — «the operating system enforces that boundary for every Bash command»; пароли и базы агенту недоступны. Отраслевая норма та же: агент дежурного сервиса PagerDuty предлагает решение и запускает только заранее утверждённые сценарии, а полностью самостоятельный режим у них — ранний доступ во втором полугодии 2026. Журнал всех действий нужен и для приёмки, и для разбора инцидентов.
